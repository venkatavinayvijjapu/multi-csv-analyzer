AI-Driven Performance Comparison for Radio Devices

Requirement: Implement an AI system that compares the performance of Radio A and Radio B across multiple metrics (SNR, EVM, Spectral Efficiency, etc.) using historical datasets. The system should process user queries, evaluate the data, and generate visualizations comparing device performance.

As a user,
I want to compare the performance of different radio devices over time using historical data,
So that I can assess improvements or regressions in performance metrics (e.g., SNR, EVM, spectral efficiency, etc.) and visualize the comparison effectively.

Purpose

To compare the performance of two radio devices—such as a legacy model and a newer one- check the datasets that capture their RF signal characteristics under similar conditions. This comparison will help you assess improvements or regressions in aspects like signal quality, stability, and efficiency.

The system should return performance scores for each metric for both devices (Radio A vs. Radio B).

Data Processing:

AI-powered Comparison:

The AI should process user queries like "Compare Radio Device A with Radio Device B" and return comparisons for the selected metrics.

If one device performs better than the other (e.g., higher SNR, lower EVM), the AI should highlight this with clear, concise output (e.g., "Radio A has better signal quality than Radio B").

Users should be able to input a natural language query (e.g., "Compare SNR of Radio A and Radio B") and receive a corresponding visual comparison.

Feedback Loop:

Users should be able to refine their queries and get updated visualizations.

The system should allow the user to toggle between different devices and metrics in the visualization.

Metric Evaluation (Details)

Signal-to-Noise Ratio (SNR): Indicates signal clarity; higher values suggest better performance.

Error Vector Magnitude (EVM): Measures modulation accuracy; lower EVM denotes higher fidelity.

Spectral Efficiency: Assesses how effectively the device utilizes bandwidth.

Frequency and Phase Stability: Evaluates the consistency of signal frequency and phase over time.

Bit Error Rate (BER): Determines the rate of errors in transmitted bits; lower BER indicates better reliability.

Power Consumption: Analyzes energy efficiency during operation.
